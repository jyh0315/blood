# 혈액형 판별 실험을 통해 알아보는 나의 ABO 혈액형

경북과학고등학교 창의과학한마당 **혈액형 판별 실험 부스**용 인터랙티브 게임 사이트입니다.

| 미션 | 내용 |
|---|---|
| LV1 원리 | 혈액형별 응집원·응집소 보기, 항체를 끌어 항원에 붙이는 짝 맞추기 게임 |
| ② 가상 실험 | 소독 → 피 내기 → 슬라이드 → 항A·항B 혈청 4방울 → 섞기 → 판정 (+ 실제 실험 결과 판정기) |
| ③ 수혈 게임 | 환자 5명에게 줄 수 있는 혈액팩 고르기 |
| ④ 유전 퍼즐 | 유전자형 교배 시뮬레이터 + 가족 혈액형 퍼즐 5개 |
| ⑤ OX 퀴즈 | 9문제 |

처음 화면에서 **저학년(LEVEL 1~3: 원리 → 가상 실험 → 쉬운 OX 퀴즈)** 또는 **고학년(LEVEL 1~5)** 모드를 고릅니다.
레벨을 깨면 큰 도장이 꽝 찍히며 효과음이 나고, 모두 모으면 "부스 스태프에게 보여주세요" 화면이 나옵니다.

캐릭터 이미지(`assets/`)는 발표 PPT의 오리·첨성대 캐릭터입니다.

## GitHub Pages로 배포하기
1. 이 폴더(`index.html`, `README.md`)를 GitHub 저장소에 올립니다.
2. 저장소 **Settings → Pages → Build and deployment**에서 Source를 `Deploy from a branch`, 브랜치 `main` / 폴더 `/ (root)`로 저장합니다.
3. 1~2분 뒤 https://jyh0315.github.io/blood/ 주소로 접속됩니다. 이 주소로 QR 코드를 만들어 부스에 붙이면 됩니다.

미션별 바로가기 링크: 주소 뒤에 `#principle`, `#experiment`, `#transfusion`, `#genetics`, `#quiz`를 붙이세요.
